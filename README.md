# neon_cirscuit

Neon Circuit — гоночная игра на Unity.

## Запуск проекта

1. Склонируйте репозиторий.
2. В Unity Hub выберите **Add project from disk** и укажите папку проекта.
3. Откройте проект в **Unity 6000.4.0f1** и дождитесь импорта ресурсов.
4. Откройте сцену `Assets/Scenes/NeonCircuit.unity` и нажмите Play.

В репозитории хранятся `Assets` (включая `.meta`), `Packages` и
`ProjectSettings`. Кэш Unity, локальные настройки и готовые сборки исключены
через `.gitignore`; Unity создаст необходимые локальные файлы при открытии.
